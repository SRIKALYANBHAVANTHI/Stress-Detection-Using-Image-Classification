# Stress Detection Using Image Classification

An academic image-classification project repository focused on stress detection. The repository groups its abstract, code, database, and project documentation into separate folders.

## Repository structure

Project materials are located in `Stress Detection Using Image Classfication/`:

- `Abstract/` — project abstract materials.
- `Code/` — implementation files.
- `Database/` — project data materials.
- `Documents/` — supporting documentation.
- `help.txt` — includes a PyTorch installation command used by the project.

## Environment note

The existing setup note references PyTorch 1.6.0 and torchvision 0.7.0 with CUDA 10.1. These are legacy versions; confirm compatibility with your Python version, operating system, and GPU/CUDA environment before installing them.

## Getting started

1. Clone the repository.
   ```bash
   git clone https://github.com/SRIKALYANBHAVANTHI/Stress-Detection-Using-Image-Classification.git
   cd Stress-Detection-Using-Image-Classification
   ```
2. Review the abstract and documentation folders.
3. Inspect the implementation under `Stress Detection Using Image Classfication/Code/`.
4. Configure the compatible Python and PyTorch environment before running the project.

The repository does not yet document the dataset schema, preprocessing pipeline, model architecture, training command, or evaluation metrics. These details should be added after validating the implementation and dataset.
